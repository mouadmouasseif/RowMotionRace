# Local Network

Recommended competition LAN:

```text
Server: 192.168.10.10
Start station: 192.168.10.30
Finish station: 192.168.10.40
Jury: 192.168.10.50
Public screen: 192.168.10.60
```

All operator devices should open:

```text
http://rowmotion.local
```

or the server IP if local DNS is not configured.

Competition functions that must work offline from the Internet:

- Start
- Finish
- Jury decisions
- Ranking
- Public local screen
- OBS local overlay
