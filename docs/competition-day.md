# Competition Day Checklist

1. Start local server.
2. Check Appwrite.
3. Check router and local DNS.
4. Connect timing stations.
5. Check start and finish buttons.
6. Check cameras.
7. Open OBS.
8. Open public screen.
9. Run system health check.
10. Load competition.
11. Arm first race.
12. Confirm jury validation workflow.

Do not launch official timing if the timing server is not ready.
